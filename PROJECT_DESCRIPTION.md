# Project description

## GitHub description

A probabilistic negotiation and communication wargame testing bounded alignment, NULL preservation, and first contact from one-bit to network scale.

## Short description

First Contact: Null Body Problem tests how unfamiliar actors negotiate, communicate, and establish bounded alignment when identity, intent, authority, and shared meaning remain uncertain.

## One-line positioning

Lock the board, exchange limited signals, preserve NULL, and measure what alignment actually survives.
